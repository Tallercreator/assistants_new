# Мои ассистенты — прототип

Прототип раздела «Мои ассистенты» на дизайн-системе Space UI Kit
(макеты Figma, раздел 41301:181913): руководитель выдаёт сотруднику полномочия на заявки,
приостанавливает, возобновляет, дублирует и удаляет ассистентов.

Живая версия: https://tallercreator.github.io/assistants_new/

Кнопка «Сценарий» в шапке переключает вариант матрицы: «Создание и согласование»
или «Только согласование» (столбца создания нет).

## Как устроено

- `main` — исходники, `gh-pages` — только собранный `dist/`, его раздаёт GitHub Pages.
- Кит подключён как `vendor/otp-space-ui-kit-*.tgz` (в git не попадает) из соседней папки
  `../../Space Design System/space-ui-kit`. Код демо — копия `src/demos/my-assistants` кита.

## Команды

```bash
npm install
npm run kit:update          # упаковать текущий dist/ кита (-- --build — сначала собрать кит)
npm run dev                 # локальный просмотр
npm run deploy              # build → gh-pages → GitHub Pages
```
